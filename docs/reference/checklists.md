# Checklists

Quick-reference checklists for each stage of the workflow.

## Pre-Launch

- [ ] All pages render correctly
- [ ] No broken links
- [ ] Images have alt text
- [ ] Meta titles and descriptions set for all pages
- [ ] Favicon configured
- [ ] Analytics set up (if required)
- [ ] Custom domain and HTTPS configured
- [ ] Robots.txt and sitemap.xml present

## Post-Launch

- [ ] Verify live URLs match expected structure
- [ ] Submit sitemap to search engines (if public)
- [ ] Confirm monitoring/alerts are active
