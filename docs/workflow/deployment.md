# Deployment

> Configure hosting, CI/CD, and go live.

## Steps

- [ ] Choose a hosting provider (GitHub Pages, Netlify, Vercel, etc.)
- [ ] Configure the deployment pipeline (GitHub Actions or provider-native)
- [ ] Set up a custom domain (if applicable) and configure DNS
- [ ] Enable HTTPS
- [ ] Verify the live site and test all pages
- [ ] Set up uptime monitoring
